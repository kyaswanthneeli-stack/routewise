How it works

01 / Classify

The initial implementation uses prompt length and explicit keywords. It has no trained semantic encoder.

02 / Select

An explicit route overrides automatic classification. Backend provider URLs, keys and model names come from server environment variables.

03 / Fail over

The Python service tries the other configured provider on timeouts, network failures, rate limits or server errors. Authentication failures are not retried.

04 / Observe

Authenticated metrics report route, attempts and measured request latency without storing raw prompts. No cost savings are claimed.
